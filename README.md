# Memory Game

Игра на поиск пар. Игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## Правила

- На поле 16 карточек: 8 пар одинаковых изображений.
- Игра начинается автоматически при загрузке страницы.
- Один ход — открытие двух карточек.
- Если изображения совпали, карточки остаются открытыми.
- Если не совпали — закрываются через 1 секунду.
- Когда найдены все 8 пар, игра завершена.
- Результаты сохраняются в таблице лидеров (localStorage).

## Технологии

- HTML
- CSS
- JavaScript (без сторонних библиотек и фреймворков)
- Вся разметка генерируется через `document.createElement`.
